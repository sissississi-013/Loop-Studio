# Loop Studio — brand and motion

## Selected logo

Asset: `loop_studio/web/loop-mark.png`. Generated with the built-in image-generation tool, then refined once using the first image as input. The compact mint ribbon has a play-shaped opening and a splice at the upper left. The original PNG and transparency are preserved; this is a raster asset, not a vector master.

## Visual references

- [Light / Motion — Z Lisenbee, Are.na](https://www.are.na/z-lisenbee/light-motion): a collection of light installations, projected grids and kinetic typography.
- [lightstream20134.jpg — Are.na block](https://www.are.na/block/169613): curved bands of illuminated text in a violet-lit room. The useful idea is type traveling around a physical ribbon, with dark negative space around it. Gemma Copeland is the collector shown by Are.na; original authorship was not established.

These are visual references only. No third-party images or videos are bundled. The landing background is an original CSS light-trail treatment, and the ASCII ribbons are original JavaScript projections with depth shading. A background video is unnecessary for this direction and would add loading cost.

## Motion behavior

The hero and character lab animate independently at a capped 24fps. Orbit, Wave and Ribbon modes, density, speed and frame download are available in the lab. Both animations start paused when reduced motion is requested; explicit playback remains available. Background trails follow the hero pause control. Character rendering stops while the page is hidden.

## Exact generation prompts

### Initial generation

Use case: logo-brand. Create one final standalone icon logo for Loop Studio, an open-source experimental video editing studio. Subject: a single bold continuous folded film ribbon forming an asymmetric rounded loop, with a clean small right-pointing play-shaped negative space in the center. The silhouette should feel like a distinctive lowercase loop/L monogram and a strip of film returning into itself, not a generic infinity sign. Flat two-dimensional Swiss graphic mark, precise geometry, soft corners, generous negative space, strong recognition at 24px. Color: one solid pale mint #B8E8C3. Truly transparent background. Square composition, symbol occupies 82 percent of frame. No text, no wordmark, no border, no mockup, no gradients, no shadows, no 3D, no film sprocket holes. Deliver a polished minimal logo icon.

### Selected refinement (first generated image supplied as reference)

A crisp flat SINGLE SOLID color pale mint #B8E8C3 with zero shading, zero grain, zero gradients, clean antialiased edges. Centered icon occupying 80% of square. Truly transparent background.
